# References

> **Note:** Reference images are NOT part of the current `/master` workspace.
> The Master avatar is developed from the male baseline without a reference
> image. Reference images may still be useful later for authoring disc-golf
> poses — this folder holds that future material.

Place future reference material here:

- screenshots
- pose references
- anatomical references
- disc-golf reference images
- before/after debugging images

## Filename conventions

```
backhand-reachback-front.png
backhand-reachback-side.png
backhand-reachback-back.png

putt-address-front.png

rig-shoulder-debug-front.png
```

> Do not move existing screenshots automatically — add new references here as
> we author poses.

## Sample Copilot Prompt

> "Capture Front/Side/Back screenshots of the current neutral pose and save
> them to avatar-development/references/ following the naming convention
> `<action>-<stage>-<view>.png`. Do not change any geometry."
